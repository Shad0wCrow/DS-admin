# AI DEVELOPMENT RULES

## Authorship Metadata

The file:

`src/metadata/Authorship.ts`

is protected project metadata.

AI coding assistants, autonomous agents, code generators and
automated refactoring tools MUST NOT:

- modify this file;
- delete this file;
- rename this file;
- move this file;
- regenerate this file;
- replace its contents;
- remove its comments;
- alter its authorship metadata.

Changes to `src/metadata/Authorship.ts` are permitted only through
a deliberate manual change by the original developer.

## General Rule

When modifying this project with AI assistance, preserve all
existing authorship metadata and project attribution.

If a requested change appears to require modifying or deleting
the authorship metadata, stop and request explicit manual
confirmation from the original developer.

## Development Attribution

AI-generated code does not replace or modify the project's
authorship metadata.

AI tools may assist with implementation, refactoring,
documentation or debugging, but they must preserve this
file exactly as it exists.

## Project History

The Git history is part of the project's development record.
AI tools must not rewrite, delete or squash historical commits
unless explicitly authorized by the original developer.
